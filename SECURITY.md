# Security

This is a static archive. It does not call model providers, run simulations, authenticate users, or collect personal data. No API keys are required. The shipped corpus is public and fictional; do not add confidential real-customer records.

The reader escapes source strings before inserting them into HTML. Exact prompts are displayed as text, not instructions to execute. Source links open existing local records; arbitrary source text cannot create executable markup.

Please report interface/security issues through the repository's GitHub security advisory facility when available. Do not post credentials or confidential material in public issues. For interface bugs without sensitive details, use a normal GitHub issue.
